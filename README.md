# miri — 피클 AI용 미리캔버스 프롬프트 스킬

Claude Code 스킬입니다. 미리캔버스 **템플릿 이름**과 **만들 주제**를 말하면,
피클 AI가 미리캔버스 안에서 그 템플릿을 찾아 **분위기·색·글꼴·배치는 그대로 두고 주제만 바꿔** 만들도록 하는 프롬프트를 써 줍니다.

## 설치

```bash
git clone https://github.com/gym-maker/miri ~/.claude/skills/miricanvas-prompt
```

Claude Code를 다시 열면 바로 쓸 수 있습니다.

## 사용 예

> 「봄 감성 카페 오픈 포스터」 느낌으로 우리 헬스장 12월 이벤트 포스터 만들어줘. 제목은 "연말 PT 30% 할인"

결과로 4단계 프롬프트(템플릿 찾기 → 지킬 스타일 → 바꿀 내용 → 마무리 점검)가 나오고, 피클 AI 채팅창에 그대로 붙여넣으면 됩니다.

## 파일

- `SKILL.md` — 스킬 본문
- `템플릿_목록.md` — 한 번 쓴 템플릿 설명을 모아 두고 다시 씁니다
